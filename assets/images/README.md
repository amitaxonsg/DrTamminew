# Website image checklist

The website is complete with graceful visual fallbacks. Replace the placeholder paths below with approved, optimised images before production launch.

## Required filenames

| File | Intended use |
|---|---|
| `dr-tammi-current.jpg` | Homepage hero and About page. Use only the current approved headshot of Dr Tammi. Do not use older or younger website portraits or the old black-jacket photograph. |
| `dr-tammi-children-approved.jpg` | Dr Tammi happily engaged in an age-appropriate developmental activity with children from a multicultural community. AI-generated image must be manually approved and labelled as illustrative. |
| `dr-tammi-family-approved.jpg` | Warm family discussion or developmental activity. Use Dr Tammi’s current facial appearance only. |
| `international-family-approved.jpg` | Inclusive family consultation visual for international families. |
| `school-collaboration-approved.jpg` | Optional illustrative discussion with a parent and education professional. No school logos or identifiable students. |
| `clinic-entrance.jpg` | Genuine clinic entrance photograph. |
| `clinic-reception.jpg` | Genuine reception photograph. |
| `clinic-waiting-1.jpg` | Genuine waiting-area photograph. |
| `clinic-waiting-2.jpg` | Optional second waiting-area photograph. |

## Mandatory portrait rule

Only the current approved headshot may represent Dr Tammi. Do not use:

- the old black-jacket image;
- a younger photo from the existing website;
- a generated face based on an older portrait;
- a stock model presented as Dr Tammi.

## Processing

Preserve original files outside the production asset directory. Export responsive WebP and AVIF versions later, retain meaningful alt text, and add explicit width and height attributes when final dimensions are known.

AI-generated scenes must display the visible caption: **Illustrative image; no actual patients shown.**
